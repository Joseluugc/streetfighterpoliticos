Fight music
-----------
Put the track you want for the fights in this folder, named one of:

  guile_theme.mp3   (tried first)
  guile_theme.ogg
  guile_theme.wav

index.html loops it automatically as the fight music (M mutes it). Use a file you own or have the
rights to use. If no file is found, the game plays its built-in chiptune loop instead.

Serve the folder with:  python3 -m http.server 8000   and open http://localhost:8000
